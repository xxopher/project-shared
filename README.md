# Singapore Property Market 2026

A single-page interactive report on Singapore's residential property market, with Q1 2026 / April 2026 data on prices, sales, and rentals.

## Files

- `report.html` — the report (self-contained, only external dependency is Chart.js via CDN)
- `research.md` — source data and outline
- `CLAUDE.md` — build brief for Claude Code

## Local

Open `report.html` in any modern browser.

## Deploy

Configured for Vercel. The root URL serves `report.html` via `vercel.json` rewrites.
